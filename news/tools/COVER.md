# 表紙のイラスト（cover.json）の作り方

翔太さんの希望（2026-11-19）：表紙のイラストは毎日変える。「その日のトピックのモチーフ、象徴をうまく一枚のイラストに昇華」する。ジャンルの扉の絵は月替わりのままで、ここでは触らない。

## 考え方
- data.json の headline と各ジャンルの先頭記事を読み、その日を象徴するモチーフを2〜3個選ぶ（多くても4個）。全部の記事を並べた寄せ集めにしない。
- モチーフを1つの場面にまとめる。たとえば「海に4隻の船（4か国の会合）、空の太陽が半導体（半導体大手の決算）、手前に檻の中のフィルム（映画監督への判決）」のように、1枚の風景や静物として成り立たせる。
- 見てすぐ分からなくてよいが、説明を読めば「なるほど」となること。説明は motif に短く書く。
- 描かないもの：実在の人物の顔や似顔絵、企業やチームのロゴ、国旗の正確な再現、文字や数字、暴力的・扇情的な描写。戦争や事故の話題は、物（地図の線、空の椅子、灯台など）に置き換えて静かに描く。

## 絵の決まり（ページのほかの絵と揃える）
- viewBox は 0 0 400 280。外側の `<svg>` タグは書かず、中身の要素だけを書く。最初に全面の背景 `<rect width="400" height="280" …/>` を置く。
- 平らな色面と黒い線だけの、切り絵のような絵。グラデーション・影・ぼかし・フィルターは使わない。線は #141414、太さ3〜5。
- 色はこの中から：黒 #141414、白 #FFFFFF、生成り #F4EFE6、ピーチ #F2A27E、空色 #A9CBEA、黄 #F4C744、グレー #C9C2B6。加えて、その日のテーマカラーを使いたい所には `{C}` と書く（ページ側で日替わりの色に置き換わる。1〜2か所の大きな面に使うとまとまる）。
- 使える要素は rect / circle / ellipse / path / line / polygon / polyline / g だけ。`<text>`、`<image>`、`<a>`、`<script>`、`<foreignObject>`、`href`、`url(…)`、`on…=` は書かない（書くとページ側で捨てられ、既定の絵に戻る）。
- 要素は40個くらいまで、全体で6000字以内。図形どうしがごちゃごちゃ重ならないよう、余白を残す。端の20pxには大事なものを置かない（画面によって少し切れる）。

## 形式
```json
{"svg": "<rect width=\"400\" height=\"280\" fill=\"#F4EFE6\"/>…", "motif": "4隻の船、半導体の太陽、檻の中のフィルム"}
```
- motif は30字以内。絵の下に「illustration / …」として出る。
- 見本は tools/cover_example.json。
- 書いたら確かめる：`python3 -c "import json,xml.dom.minidom as m;d=json.load(open('cover.json'));m.parseString('<svg>'+d['svg']+'</svg>');print(len(d['svg']))"` がエラーにならないこと。できれば絵にして一度目で見る（例：svg を `<svg xmlns="http://www.w3.org/2000/svg" viewBox="0 0 400 280">…</svg>` で包み、`{C}` を #FFDD33 に置き換えてファイルにし、Playwright などで画像にして確認する。重なりや切れがあれば直す）。
- うまく描けなかった日は cover.json を作らなくてよい（既定の絵が出る）。10分を目安に。
